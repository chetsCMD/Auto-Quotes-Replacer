# Auto-Quotes-Replacer

## En
Replace '&lt;&lt;' and '>>' with '«' and '»' respectively in Obsidian.
### Download
1. [Download the latest release](https://github.com/chetsCMD/Auto-Quotes-Replacer/releases)
2. Open Obsidian, go to Settings → Community Plugins → Manage Plugins → Open plugins folder
3. Create a folder named "auto-quotes-replacer" and place the previously downloaded files there
4. Restart Obsidian, then enable the plugin in the Community Plugins settings and set up a hotkey for replacing quotes

## Ru
Заменяйте "&lt;&lt;" и ">>" на "«" и "»" соответственно в Obsidian
### Скачивание
1. [Скачайте последний релиз](https://github.com/chetsCMD/Auto-Quotes-Replacer/releases)
2. Откройте Obsidian, перейдите в настройки → Сторонние плагины → Управление плагинами → Открыть папку с плагинами
3. Создайте папку "auto-quotes-replacer" и положите туда ранее скаченные файлы
4. Перезапустите Obsidian, в управлении плагинами включите плагин и настройте бинд для замены кавычек
